## Módulo de aniversários

Nas configurações do módulo, selecione uma planilha `.xlsx`, `.xls`, `.xlsm` ou `.csv`, ou informe uma URL acessível de CSV/Excel. Para uma planilha Google, habilite o acesso de leitura pelo link e cole o link de edição/compartilhamento ou publicação. A primeira linha deve conter os cabeçalhos; as colunas de nome, data de nascimento/data e cor (hexadecimal, com ou sem `#`) são reconhecidas pelos títulos. As datas são exibidas em ordem de mês e dia, mesmo quando a planilha usa `dd/mm/aaaa` ou `aaaa-mm-dd`.

Para incluir um evento manual, abra o calendário, escolha um mês e use o botão `+`. Informe uma data `dd/mm` para um evento anual ou `dd/mm/aaaa` para um evento único; a imagem é opcional. Clique em um item para ver o nome, a contagem de dias e a imagem; eventos manuais podem ser removidos pelo botão `−`. Os eventos e as imagens escolhidas ficam em arquivos temporários do Windows, não dentro da pasta do projeto. Em Personalização, escolha se o indicador das páginas aparece como bolinhas (padrão) ou números.
